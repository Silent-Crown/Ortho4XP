<objective>
**User story:** **As a** scenery scripter, **I want to** list what terrain is already built
and flag half-finished or crashed tiles, **so that** I can trust my inventory before
scheduling more builds.

Two remaining read-only reports built on the Plan 01 shared predicate: `report tiles`
(inventory — provider, zoom, build date, on-disk size, RPT-01) and `report health`
(structural staleness — partial tiles and crashed-run leftovers, RPT-03). Both reuse
`tile_status` (D-05) so all three reports speak one built/partial/missing vocabulary.

Purpose: complete the phase's report surface (`report tiles`/`report health` bodies replace
the Plan 01 stubs).
Output: the finished inventory and health commands.

**RESEARCH deviation (D-09):** the per-tile config file is `Ortho4XP_<latlon>.cfg` (no `z`;
the `z` is only on the directory `zOrtho4XP_<latlon>/`). Reading the wrong filename makes
every tile report a blank provider/zoom.
</objective>
