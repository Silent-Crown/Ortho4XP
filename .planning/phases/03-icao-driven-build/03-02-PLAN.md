<objective>
Fix G-03-7: `resolve_icao` only classifies `code == "AIRPORT_DETAILS_ERROR"` as `ICAONotFound`, but
the real mcp_aviation_server returns `code == "AIRPORT_NOT_FOUND"` for an unknown ICAO. That code
falls through to the `AviationServerUnreachable` abort branch, so one bad ICAO in a batch kills the
whole run instead of being skipped (D-10). The bug was masked because `tests/conftest.py`'s
not-found fixture hard-codes the wrong code string.

Purpose: an unknown ICAO in `--icao KJFK,ZZZZ` must skip ZZZZ and still build KJFK.
Output: `resolve_icao` correctly classifies the real not-found code; fixture and tests reflect it;
a real end-to-end (non-mocked resolver) test proves the batch skip path.
</objective>
