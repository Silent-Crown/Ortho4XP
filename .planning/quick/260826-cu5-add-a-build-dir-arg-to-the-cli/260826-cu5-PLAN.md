# Quick Task 260826-cu5: add a --build-dir arg to the CLI

Add a `--build-dir` option to the `build` subcommand so headless builds can
target a tile store other than the default `./Tiles`, matching the GUI's
"Base Folder" (custom_build_dir). Previously the CLI hardcoded
`CFG.Tile(lat, lon, '')`, ignoring any base folder.

## Tasks

1. Thread `build_dir` through `run_build` and `run_batch_build` into
   `CFG.Tile(lat, lon, build_dir)` (src/O4_CLI_Utils.py).
2. Add `--build-dir` to the `build` subparser and pass `args.build_dir` from
   `dispatch`.
3. Batch guard: force base-folder semantics (trailing separator) so multiple
   tiles nest instead of colliding into one literal dir.
4. Extend the `__main__` self-check to cover the new arg.
